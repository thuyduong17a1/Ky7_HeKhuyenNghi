## 1. Mô tả đề tài
Hệ thống tư vấn khuyến nghị xe cũ dựa trên thuật toán Case-Based Reasoning (CBR) kết hợp cơ chế Critiquing (phê bình tương tác) trên tập dữ liệu Car Dekho.

## 2. Dữ liệu & Công nghệ
- **Tập dữ liệu:** Car Dekho Used Cars (4,340 bản ghi)
- **Công nghệ:** Python, Pandas, Numpy, Scikit-learn 

## 3. Cấu trúc thư mục
- `Code_DoThuyDuong.ipynb`: File code hoàn chỉnh bao gồm tiền xử lý dữ liệu, cài đặt thuật toán CBR/Critiquing và mô phỏng đánh giá.
- `CAR DETAILS FROM CAR DEKHO.csv`: Tập dữ liệu gốc xe cũ.
